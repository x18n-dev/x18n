---
title: DevTools
description: Open the x18n UI as a panel of Vite DevTools, Nuxt DevTools or any devframe hub, next to your app.
---

`@x18n/devtools` puts the [x18n UI](/surfaces/ui) in the devtools of your app, so you do not need a separate `x18n ui` server. The panel is the same UI with the same pages. It reads and writes the files of the project, and it updates when the files change.

| Host | Import |
| --- | --- |
| [Vite DevTools](https://devtools.vite.dev/) | `X18nDevtools` from `@x18n/devtools/vite` |
| [Nuxt DevTools](https://devtools.nuxt.com/) 4 and later | `X18nDevtools` from `@x18n/devtools/vite` |
| A [devframe hub](https://devfra.me/guide/hub) | `createX18nDevframe` from `@x18n/devtools/devframe` |

The panel loads the project from the root of the host (the Vite root). From there, x18n searches upward for a config file, as the CLI does. Install the package as a dev dependency:

```sh
pnpm add -D @x18n/devtools
```

## Vite DevTools

Add the plugin after `DevTools()`:

```ts [vite.config.ts]
import { DevTools } from '@vitejs/devtools'
import { X18nDevtools } from '@x18n/devtools/vite'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [DevTools(), X18nDevtools()],
})
```

Start the dev server and open Vite DevTools. The x18n panel is in the dock. Vite DevTools signs you in with its own auth code. The panel then needs no other sign-in.

## Nuxt DevTools

Nuxt DevTools 4 runs on Vite DevTools, so the same plugin works. Add it to the Vite config of Nuxt:

```ts [nuxt.config.ts]
import { X18nDevtools } from '@x18n/devtools/vite'

export default defineNuxtConfig({
  devtools: { enabled: true },
  vite: {
    plugins: [X18nDevtools()],
  },
})
```

## A devframe hub

`createX18nDevframe()` returns a devframe definition. Mount it in any hub, for example `viteDevframeHub` from `@devframes/vite/hub`:

```ts [vite.config.ts]
import { viteDevframeHub } from '@devframes/vite/hub'
import { createX18nDevframe } from '@x18n/devtools/devframe'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [viteDevframeHub({ devframes: [createX18nDevframe()] })],
})
```

The hub owns the auth gate and the URL. The panel is at `<hub base><id>/`, for example `/__devframes/x18n/`.

## Options

Both functions take the same options:

| Option | Effect |
| --- | --- |
| `root` | The project root. The default is the root of the host, and x18n searches upward for a config file from there. With `root`, x18n does not search upward. |
| `config` | A config file to use instead of searching for one. |

To open files from the panel in your editor, set `LAUNCH_EDITOR`, `VISUAL` or `EDITOR` before you start the dev server.
