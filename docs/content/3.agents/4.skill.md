title: The x18n skill
description: The agent skill that ships in @x18n/cli and teaches an agent to set up x18n and manage translations.
---

An agent skill is a markdown file that teaches a coding agent how to do a task. The `@x18n/cli` npm package ships one at `skills/x18n/SKILL.md`. The version of the skill always matches the version of the CLI that you install.

The skill tells the agent:

- how to set up x18n in a project: check what x18n detects with `x18n doctor`, write a config only when detection needs help, and add `x18n check` to the scripts,
- which decisions to leave to you, and to ask about them in one message: the locales, key naming, glossary terms and their translations, tone per locale, deleting unused keys, large renames, and stricter checks,
- to keep a terms table: the [`glossary`](/references/config) in the config. The agent reads it before it translates, proposes new terms with translations, adds the ones you approve, and turns on the `glossary` check,
- to use x18n instead of editing locale files by hand, to check whether a key exists before it uses one, and to keep placeholders,
- the loops of [Agent workflows](/agents/workflows): check, add a key, translate, review, clean up, rename and extract,
- to read the `--json` output and the exit codes, to page large outputs, and to pick a project in a monorepo.

A reference next to the skill, `references/migrate-i18n-ally.md`, walks the agent through a [migration from i18n-ally](/migration): record a baseline, preview the migration, ask about what it drops, write the files, compare with the baseline, and remove the i18n-ally settings once you agree.

## Install the skill

The skill is in `node_modules/@x18n/cli/skills/x18n/` after you install `@x18n/cli`. Agents do not read `node_modules`, so link the skill into the directory that your agent reads. [skills-npm](https://github.com/antfu/skills-npm) does this for every package that ships skills:

```sh
npm i -D skills-npm
npx skills-npm setup
```

`skills-npm setup` adds itself to the `prepare` script of `package.json`. After that, every install links the skills again, so the skill stays at the version of the installed CLI.

You can also copy the `node_modules/@x18n/cli/skills/x18n/` directory into the skills directory of your agent by hand. Copy it again when you update x18n.

## Read it

The source of the skill is [`packages/cli/skills/x18n/SKILL.md`](https://github.com/antfu/x18n/blob/main/packages/cli/skills/x18n/SKILL.md). A test in the repository makes sure that every command and flag that the skill and its reference name exists in the CLI.
