---

The `polyglot` preset supports [Polyglot.js](https://airbnb.io/polyglot.js) by Airbnb.

## Detection

The preset applies when the project depends on `node-polyglot`.

```ts [x18n.config.ts]
import { polyglot } from '@x18n/cli/presets'
import { defineConfig } from '@x18n/core'

export default defineConfig({
  presets: [
    polyglot()
  ],
})
```

## Locale files

The preset adds no resource patterns. Set `resources` in the config, or let x18n guess the locale directories. For example, x18n finds `translations/en.json` without a config.

## Supported syntax

`polyglot.t` and `I18n.t` are translate calls in JS and TS:

```js [src/a.js]
polyglot.t('a.b')
```

In Ruby files, the preset reads the same two calls with a regex.

## Placeholders

Percent braces: `%{name}`.

## Extraction templates

| Kinds | Template |
| --- | --- |
| `js-string`, `js-template` | `polyglot.t('{key}'{args})` |
