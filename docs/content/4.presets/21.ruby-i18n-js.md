---

The `ruby-i18n-js` preset supports [i18n-js](https://github.com/fnando/i18n), the JS companion of Rails I18n.

## Detection

The preset applies when the project depends on `i18n-js`.

```ts [x18n.config.ts]
import { defineConfig } from '@x18n/core'

export default defineConfig({
  presets: ['ruby-i18n-js'],
})
```

## Locale files

The preset adds no resource patterns. Set `resources` in the config, or let x18n guess the locale directories. For example, x18n finds `translations/en.json` without a config.

## Supported syntax

`I18n.t` and `i18n.t` are translate calls:

```js [src/a.js]
I18n.t('a.b')
```

## Placeholders

Percent braces: `%{name}`.

## Extraction templates

| Kinds | Template |
| --- | --- |
| `js-string`, `js-template` | `i18n.t('{key}'{args})` |
