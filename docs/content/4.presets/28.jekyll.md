title: jekyll
description: The preset for jekyll-multiple-languages-plugin. It reads _i18n YAML files and the t Liquid tag.
---

The `jekyll` preset supports [jekyll-multiple-languages-plugin](https://github.com/kurtsson/jekyll-multiple-languages-plugin).

## Detection

The preset applies when the `Gemfile` has `jekyll-multiple-languages-plugin`.

```ts [x18n.config.ts]
import { jekyll } from '@x18n/cli/presets'
import { defineConfig } from '@x18n/core'

export default defineConfig({
  presets: [
    jekyll()
  ],
})
```

## Locale files

If your config has no `resources`, the preset uses `_i18n/{locale}.yml`. New files use nested keys.

## Supported syntax

In `.html`, `.md` and `.liquid` files, the preset reads the `t` tag:

```liquid [index.html]
<a>{% t nav.home %}</a>
```

This is a usage of `nav.home`.

## Placeholders

The preset adds no placeholder syntax.

## Extraction templates

| Kinds | Template |
| --- | --- |
| any | `{% t {key} %}` |
