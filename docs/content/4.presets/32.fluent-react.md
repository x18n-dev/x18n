The `fluent-react` preset supports [@fluent/react](https://projectfluent.org/fluent.js/react/), the React binding of [Project Fluent](https://projectfluent.org).

## Detection

The preset applies when the project depends on `@fluent/react`.

```ts [x18n.config.ts]
import { fluentReact } from '@x18n/cli/presets'
import { defineConfig } from '@x18n/core'

export default defineConfig({
  presets: [fluentReact()],
})
```

## Locale files

If your config has no `resources`, the preset uses `public/locales/{locale}/*.ftl`, `locales/{locale}.ftl` and `src/locales/{locale}.ftl`. The `ftl` format reads and writes these files. All `.ftl` files of a locale share one set of keys, as in a Fluent bundle.

The `ftl` format reads a message attribute as a key of its own: `.title` on the message `login` is the key `login.title`.

## Supported syntax

The `id` prop of `<Localized>` is a key. These names count as translate calls: `l10n.getString`, `getString`, `props.getString` and `this.props.getString`. `useLocalization()` returns `l10n`, and `withLocalization` gives the `getString` prop.

<!-- eslint-skip -->

```tsx [src/App.tsx]
function Greeting({ name }) {
  const { l10n } = useLocalization()
  return (
    <Localized id="hello" vars={{ name }}>
      <p title={l10n.getString('hello-title')}>Hello</p>
    </Localized>
  )
}

function Bye({ getString }) {
  return <p>{getString('bye')}</p>
}

export default withLocalization(Bye)
```

## Placeholders

Fluent variables: `{ $name }`. For `hello = Hello { $name }` in `en` and `hello = Hallo` in `de`, the [`placeholder-mismatch`](/checks/placeholder-mismatch) check reports `hello`.

## Extraction templates

| Kinds | Template | Imports |
| --- | --- | --- |
| `jsx-text` | `<Localized id="{key}" />` | `import { Localized } from '@fluent/react'` |
| `jsx-attribute` | `{attr}={l10n.getString('{key}'{args})}` | |
| `js-string`, `js-template` | `l10n.getString('{key}'{args})` | |

`<Localized>` without children renders the message as text. The `l10n` templates need `const { l10n } = useLocalization()` in the component.
