---
title: flutter-translate
description: The preset for flutter_translate. It reads translate() and translatePlural() calls in Dart and nested plural keys.
---

The `flutter-translate` preset supports [flutter_translate](https://pub.dev/packages/flutter_translate).

## Detection

The preset applies when `pubspec.yaml` has the dependency `flutter_translate`.

```ts [x18n.config.ts]
import { flutterTranslate } from '@x18n/cli/presets'
import { defineConfig } from '@x18n/core'

export default defineConfig({
  presets: [flutterTranslate()],
})
```

## Locale files

If your config has no `resources`, the preset uses `assets/i18n/{locale}.{ext}`.

## Supported syntax

In Dart files, the preset reads `translate` and `translatePlural`:

```dart [lib/main.dart]
Text(translate('app_bar.title'));
Text(translatePlural('plural.demo', _counter));
```

These usages are `app_bar.title` and `plural.demo`.

flutter_translate keeps plural forms as nested keys. The preset adds the derived keys `{key}.zero`, `{key}.one`, `{key}.two`, `{key}.few`, `{key}.many` and `{key}.other`, so the [`unused-key`](/checks/unused-key) check does not report the forms of a used key.

## Placeholders

Braces: `{name}`. Double braces: `{{value}}`, the count in plural forms.

## Extraction templates

| Kinds | Template |
| --- | --- |
| any | `translate('{key}')` |
