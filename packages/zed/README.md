# x18n for Zed

The Zed extension starts `@x18n/lsp` and passes Zed settings to the language server. i18n analysis stays in the LSP package. The Zed registry extension path is `packages/zed`. The registry builds WASM from source.

## Develop locally

Use Node.js 22+, Rust stable with `wasm32-wasip2`, and Zed's extension API 0.7.

```sh
pnpm install
cd packages/zed
rustup target add wasm32-wasip2
cargo build --release --target wasm32-wasip2
```

In Zed, choose **Extensions → Install Dev Extension** and select `packages/zed`. Grant `npm:install` for `@x18n/lsp` and `process:exec` for Node when prompted. `extension.wasm` is generated by Zed and must not be committed.

The package checks are `pnpm test`, `cargo test`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo build --release --target wasm32-wasip2`. Node tests use `node --test` against published `@x18n/lsp` (catalog range `^0.1.5`). Rust tests cover the extension's server selection. [Editor smoke checks](./docs/e2e-smoke.md) remain manual.

## Language server selection

| Priority | Source | When |
| --- | --- | --- |
| 1 | `lsp.x18n.binary` | Explicit command override |
| 2 | `<worktree>/node_modules/@x18n/lsp/bin.mjs` | `useLocalServer` is true (default) and the project has the package |
| 3 | `npx -y @x18n/lsp@<version> --stdio` | `useNpx` is true and `npx` is on `PATH` |
| 4 | Extension-managed npm install | Default version 0.1.5 |

The extension sends `worktreeRoot` in LSP initialization options. Empty `workspaceFolders` falls back to `rootUri` in `@x18n/lsp` 0.1.5 and later. See [workspace-folder notes](./docs/workspace-folders.md).

## Zed settings

Add settings to the user or project `.zed/settings.json`:

```json
{
  "lsp": {
    "x18n": {
      "settings": {
        "useLocalServer": true,
        "useNpx": false,
        "serverVersion": "0.1.5",
        "displayLocale": "",
        "annotationMaxLength": 40,
        "codeLens": false,
        "showFlags": true
      }
    }
  }
}
```

The extension covers JavaScript, JSX, TypeScript, TSX, Vue.js, JSON, JSONC, YAML, HTML, Svelte, and Astro. Zed exposes the server's hover, navigation, rename, completion, diagnostics, code actions, and hints. VS Code-only views and controls are described in the [VS Code package](../vscode/README.md).
